# Japan IPTV Research

URL-free research registry for Japan IPTV candidates.

This repository stores safe metadata only:

- research registries
- source/system classification
- local-station EPG mapping helpers
- local-only M3U builder templates

## Safety rules

- No direct playback URLs
- No token/vhash/ac_tk values
- No p2p/p5p entries
- No premium-channel playback identifier lists
- Private stream URLs must stay in local-only CSV files
